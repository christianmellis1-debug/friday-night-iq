# Friday Night IQ

Football playbook and team preparation Streamlit prototype.

**Development demo only:** no coach/player authentication, isolated production workspaces, or durable cloud storage. Use fictional data only; do not upload actual student records or confidential playbooks.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The starter includes a coach dashboard, position-filtered play library, imports, weekly installs and player study preview. See project documentation for limitations.
